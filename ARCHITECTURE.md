# Secure AI Pipeline Architecture
User Prompt
↓
FastAPI API
↓
Prompt Injection Filter
↓
AI Response Generator
↓
Data Leakage Filter
↓
Security Logger
↓
Security Dashboard
↓
Promptfoo Automated Security Testing

### Components

FastAPI API  
Handles incoming prompts from users.

Prompt Injection Filter  
Blocks malicious prompts attempting to override system instructions.

AI Response Generator  
Simulated AI model response.

Data Leakage Filter  
Prevents exposure of sensitive information.

Security Logger  
Records security events for monitoring.

Promptfoo Testing  
Automatically tests the system against AI security threats.
